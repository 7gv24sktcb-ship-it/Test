What this bench does. It collects the two inputs a TDK press release needs, assembles every fixed part of the document for you, and packages the whole thing as one briefing packet you paste into Claude to write the prose.

It does not write the release itself — a published page cannot call a language model, so the drafting step stays in Claude, where the tdk-press-release skill applies the same rules encoded here.
