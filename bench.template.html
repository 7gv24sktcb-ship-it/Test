What this bench does. Drop both source documents as PDF or Word. The bench reads the text out of them in your browser, assembles every fixed part of the release, and packages the whole thing as one briefing packet you paste into Claude to write the prose.

It does not write the release itself — a published page cannot call a language model, so the drafting step stays in Claude, where the tdk-press-release skill applies the same rules encoded here. Nothing you drop leaves this browser.
